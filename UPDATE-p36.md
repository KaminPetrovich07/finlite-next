# FinLite KG — патч p36: сверка с 1С

Ставится поверх p35. Схема базы не меняется, `prisma db push` не нужен.

## Учёт → «Сверка с 1С» (новый раздел, /reconcile)
- Загрузите **оборотно-сальдовую ведомость из 1С** за месяц (Excel). Программа сравнит её с журналом FinLite
  за тот же период по каждому счёту: сальдо на начало, обороты по дебету и кредиту, сальдо на конец.
- **Счета 1С сопоставляются как на странице «Обмен с 1С»** (план КР — 1:1, план РФ — 41 → 1610, 62 → 1410 …);
  сопоставление общее. Несопоставленные счета показываются отдельно — их можно указать и сохранить.
- **Доходы и расходы** сравниваются по основному обороту (выручка — кредит, расходы — дебет): 1С закрывает их
  на прибыль каждый месяц, FinLite — при закрытии года. Сверху — прибыль за период по 1С и по FinLite.
- **Если ведомость развёрнута по субконто** — сверка по контрагентам (1410, 3110, авансы …) и по номенклатуре
  (16xx). «ОсОО», кавычки и регистр в наименованиях не мешают.
- По каждому расхождению — **подсказка, где искать** (остатки на начало, реализации, НДС, себестоимость,
  запасы, расчёты, деньги) и **операции FinLite по счёту за период** со ссылками в журнал — чтобы сверить
  с карточкой счёта в 1С.
- Фильтр «только расхождения», выгрузка сверки в **Excel**.

## Исправление загрузки документов из 1С (p35)
- Если номер из 1С уже занят **другим** документом (другой контрагент или сумма), документ не загружается
  и попадает в список «проверьте нумерацию» — раньше он молча считался повтором.
