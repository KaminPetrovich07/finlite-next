# p48 — управленческий учёт, этап 1: аналитики и прибыль по сегментам

Анализ → **Управленческий учёт**.

## Аналитики
- Три вида: **подразделение (ЦФО)**, **проект / объект**, **направление**. Значения задаёт бухгалтер;
  у каждого — роль: центр прибыли или центр затрат; ненужные — в архив.
- Объекты раздела «Стройка» сами становятся значениями «Проект / объект», их проводки размечаются сами.

## Разметка проводок
- **Правила**: счёт (или его начало), контрагент, слова в описании, источник проводки → значения аналитик.
  Проверяются сверху вниз, первое подходящее задаёт значение.
- **Вручную**: в таблице проводок периода — выбор у каждой проводки или сразу у отмеченных.
  Выбор вручную важнее правила; «—» возвращает значение по правилу. Видно, откуда значение: вручную / правило / стройка.
- Фильтр «без значения …» — что ещё не размечено.

## Прибыль по сегментам
- По подразделениям, проектам или направлениям: выручка, себестоимость, валовая прибыль, расходы по
  реализации, административные, прочие, **вклад сегмента**, **распределённые общие затраты**,
  операционная прибыль, неоперационные статьи, налог, чистая прибыль; маржа, рентабельность, доли.
- Общие (неразмеченные) операционные затраты распределяются: пропорционально выручке, прямым затратам,
  поровну, вручную в %, или не распределяются. База — своя для каждого вида аналитики.
- Предупреждения: выручка без сегмента, убыточный после распределения сегмент, центр прибыли без выручки.
- Диаграмма прибыли сегментов; отчёт в PDF и Word.
- Демо-мебельщик: цех, отдел продаж, салон, администрация; направления B2B и розница — по правилам.

Схема базы не меняется (настройки и разметка — в CompanyRecord). Разметка относится к проводке целиком.
