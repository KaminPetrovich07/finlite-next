# FinLite KG — патч p31: номенклатура, реализация и поступление

## Учёт → «Номенклатура» (новый раздел)
- Справочник товаров, материалов, готовой продукции и услуг: наименование, артикул, группа,
  единица по ОКЕИ, цена закупки, цена продажи, НДС (12 % / 0 % / без НДС).
- **Загрузка из 1С:** в 1С «Номенклатура» → «Ещё» → «Вывести список…» → «Сохранить» как Excel (.xlsx)
  → «Загрузить из 1С / Excel». Понимает иерархический список с группами, столбцы «Артикул»,
  «Единица», «Вид номенклатуры», «Цена», «Ставка НДС». Перед загрузкой показывает, что нашлось.
  Подходит и любой прайс в Excel. Повторная загрузка обновляет позиции (по артикулу, затем по названию).
- **«Собрать из журнала проводок»** — позиции, которые уже есть в проводках и остатках (например, после
  загрузки ОСВ по счёту 41/1610 с количеством из 1С на странице «Обмен с 1С»), с последними ценами.
- Правка, удаление, удаление списком, поиск и фильтр по виду.

## Учёт → «Продажи и закупки» (новый раздел)
- Документы **«Реализация»** и **«Поступление»** с таблицей строк: номенклатура (подсказка из справочника —
  единица, вид, цена и НДС подставляются сами), количество, цена, НДС, сумма; итоги без НДС, НДС, всего.
- «Цены включают НДС» (12/112) или НДС сверху (12 %). Оплата: в долг, наличными, на расчётный счёт.
- Номер реализации — сквозной по году, подставляется сам и не повторяется; у поступления — номер документа поставщика.
- В реализации видно, сколько товара на складе на дату документа, и предупреждение, если продаёте больше, чем есть.
- **Проводка формируется сама:** реализация — Дт 1410/1110/1210, Кт 6110 по строкам с номенклатурой
  и количеством, Кт 3430 НДС; поступление — Дт 1610/1620/1640 (по виду) или 8040 (услуги), Дт 1540 НДС, Кт 3110/1110/1210.
  Склад, себестоимость (если включено автосписание), отчёты, акты сверки с контрагентами и ЭСФ берут данные из неё.
- **Печать в один клик:** накладная и счёт на оплату (реализация), приходный ордер М-4 (поступление) — PDF или Word.
  В накладной и счёте теперь отдельно «Итого без НДС», «НДС 12 %», «Всего с НДС» (и для ручных проводок с НДС).
- Новые позиции, введённые прямо в документе, сами попадают в номенклатуру.
- Документ можно открыть, изменить (проводка пересчитается, прежняя версия — в истории) и удалить
  (вернуть — в журнале, «Удалённые»). Если два человека правят один документ — второму предложат открыть заново.

Схема базы не меняется — `prisma db push` не нужен.
