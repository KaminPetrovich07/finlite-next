# p45 — отчётность предприятий, ведомства, защита, земельные участки

## Отчётность предприятий (Анализ → Отчётность предприятий)
- Шаблон Excel: баланс, доходы и расходы, просроченная задолженность по видам; сом / тыс. сом; за квартал / нарастающим итогом.
- Загрузка пачкой, разбор в браузере, проверка расхождений до загрузки.
- Портфель и финансовая диагностика (PDF/Word) по квартальной отчётности — без ведения учёта в программе.
- Пример: 4 вымышленных госпредприятия за 6 кварталов.

## Ведомства (Админ → Ведомства)
- Доступ сотрудника министерства ко всем предприятиям группы, включая будущие; «просмотр» — без права изменять.

## Защита
- FL_REQUIRE_ADMIN_2FA=on — раздел администратора только с двухфакторным входом.
- FL_IDLE_MINUTES — выход по бездействию; по умолчанию выключен везде.
- Журнал действий — цепочка SHA-256; «Админ → Система → Проверить целостность»; отпечаток раз в сутки в журнал сервера.
- Входы и неудачные попытки хранятся весь срок журнала (FL_AUDIT_DAYS).

## Земельные участки (Учёт → Земельные участки)
- Реестр: код ЕНИ, категория, вид угодий, площадь, право, документы, аренда и её срок; выгрузка в Excel.
- Налоговая стоимость = площадь × БНС × Ки (НК КР ст. 400–401); БНС, Ки и ставку вводит бухгалтер.
