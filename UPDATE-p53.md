# p53 — все документы бланковой вёрсткой альбома, по нескольку на листе

- Шапка как в альбоме: субъект и подразделение на строках с подписями под ними, справа гриф «Форма № …» и клетки «Код / по ОКПО».
- Заголовок «Приходный ордер № 5 от 03.07.2026» одной строкой; «Номер документа», «Дата составления», «Код вида операции», «Отчётный период с … по» — в клетках.
- Поля — на подчёркнутых строках, короткие по два в ряд; подписи — «должность ___ подпись ___ расшифровка», по две в ряд.
- Узкие поля, мелкий кегль, без колонтитула — как печатный бланк.
- «Скачать все»: документы идут подряд и не разрываются между листами — что помещается, ставится на один лист
  (накладные и счета — по 3 на А4, короткие М-4/М-11 — по 2), между ними пунктир для разрезания.
- То же в «Торговле» (накладная + счёт на одном листе), в «Стройке» (КС-2, КС-3, акт, списание) и у всех 134 бланков альбома.
- PDF и Word; на кыргызском тоже.
