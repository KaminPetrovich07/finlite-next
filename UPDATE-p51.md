# p51 — документы из журнала по бланкам альбома унифицированных форм КР

Первичные документы, которые FinLite заполняет из журнала, теперь печатаются **по бланкам альбома**
(тем же, что в разделе «Бланки»): те же графы и подграфы с номерами граф, «Форма № …» / «Утверждена
постановлением Нацстаткомитета КР от 07.04.2003 № 4», наименование субъекта, структурное подразделение,
код по ОКПО, оборотные стороны, подписи и «Утверждаю», альбомная ориентация там, где она в альбоме.

## Документы (Документы → Первичные документы, Продажи и закупки)
- **КО-1** приходный кассовый ордер с квитанцией (Форма по ГКУД, кредит: код подразделения, корр. счёт, код аналитического учёта, код целевого назначения);
- **КО-2** расходный кассовый ордер;
- **АО-1** авансовый отчёт (бухгалтерская запись и перечень документов на обороте);
- **М-4** приходный ордер — 12 граф альбома: наименование, номенклатурный номер, код и наименование единицы по ОКЕИ, по документу / принято, цена, сумма без НДС, НДС, всего с НДС, № паспорта, № по картотеке;
- **М-11** требование-накладная, **М-15** накладная на отпуск материалов на сторону;
- **ОС-1** акт приёмки-передачи ОС (15 граф, оборотная сторона), **ОС-4** акт на списание ОС;
- **Т-49** расчётно-платёжная ведомость, **Т-53** платёжная ведомость.

## Регистры
- **КО-3** журнал регистрации кассовых документов (приход и расход — в своих графах);
- **ИНВ-15** акт инвентаризации наличных денег, **ИНВ-3** опись ТМЦ (по номенклатуре, код ОКЕИ, цена), **ИНВ-1** опись ОС;
- **М-2** доверенность;
- для **ИП** — журнал продаж и журнал закупок по рекомендованным формам альбома (у юрлиц — сводные регистры, как раньше).
- Кассовая книга по дням, книга оплаты труда и книга ОС остаются сводными.

## Стройка
- **КС-2** и **КС-3** — по формам альбома «Первичные документы в строительстве» (№ 111, 112, неунифицированные):
  инвестор, заказчик, подрядчик с ИНН, стройка, объект, договор, номер, дата, отчётный период; графы в порядке альбома.

Накладная, счёт и акт услуг — форма организации (в альбоме их нет) — без изменений. Документы на кыргызском
(М-4, накладная, счёт, акт) переводят и новые графы бланка.

Схема базы не меняется.
